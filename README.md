# Basic activities 
Data consumption test, fake REST API

Consumes the JSON data from this repository: https://github.com/brlivramento/json_system_activities

A basic project created in 2018 for the sole purpose of helping, which I decided to publish
    
## Run Locally

1. Clone the project

```bash
  git clone git@github.com:brlivramento/basic_system_activities.git
  cd basic_system_activities
```

2. Build docker

```bash
  docker compose up --build
```
